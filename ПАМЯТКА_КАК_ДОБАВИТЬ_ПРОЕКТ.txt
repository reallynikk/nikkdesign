==============================================================================
         ПАМЯТКА: КАК ЛЕГКО ДОБАВИТЬ НОВЫЙ ПРОЕКТ В ПОРТФОЛИО
==============================================================================

Каждый проект на вашем сайте хранятся в своем отдельном файле в папке:
  `js/projects/`

Вы добавляете файл проекта — и он АВТОМАТИЧЕСКИ появляется на сайте:
  1. В верхнем 3D слайдере (Coverflow) на главном экране.
  2. В основной сетке проектов (с автоматической сортировкой по году).
  3. Во вкладках-фильтрах категорий.
  4. В полном интерактивном модальном окне с альбомами фото и зумом (Lightbox).

------------------------------------------------------------------------------
ШАГ 1. Загрузите изображения проекта
------------------------------------------------------------------------------
1. Перейдите в папку `images/` в директории сайта.
2. Создайте там папку для нового проекта (например: `images/MyNewProject/`).
3. Положите туда файлы обложек, футболок, бейджей и полиграфии.

------------------------------------------------------------------------------
ШАГ 2. Создайте новый JS-файл проекта
------------------------------------------------------------------------------
В папке `js/projects/` создайте новый файл (например: `myproject.js`).
Скопируйте и заполните в него этот шаблон:

export const myproject = {
  id: 'myproject',                          // Уникальный ID латиницей (без пробелов)
  year: 2026,                               // Год разработки (для сортировки)
  filterCategory: 'branding',               // Категория: 'branding' | 'merch' | 'graphic' | 'polygraphy'
  badgeText: '✦ 2026 • МЕРЧ',                // Плашка на карточке
  tagline: '2026 • КРАТКИЙ ТЕГ',            // Верхний тег в кейсе
  category: 'Брендинг & Дизайн • 2026',     // Полное название категории
  title: 'Название Моего Проекта',          // Заголовок
  subtitle: 'Подзаголовок проекта в одно предложение',
  cardDescription: 'Описание для карточки в сетке проектов на главной странице.',
  previewImage: 'images/MyNewProject/preview.png', // Главная обложка для сетки
  heroImage: 'images/MyNewProject/hero.png',       // Фото для 3D слайдера и шапки кейса
  featuredInHero: true,                      // true — покажет в верхнем 3D слайдере
  task: 'Описание задачи проекта: что требовалось разработать и какая цель.',
  deliverables: [
    'Пункт 1: Что именно было разработано',
    'Пункт 2: Дизайн мерча / полиграфии',
    'Пункт 3: Подготовка векторных макетов'
  ],
  tools: ['Figma', 'Photoshop', 'Illustrator'], // Используемые инструменты
  galleryImages: [
    { src: 'images/MyNewProject/photo1.png', caption: 'Описание 1-го фото' },
    { src: 'images/MyNewProject/photo2.png', caption: 'Описание 2-го фото' }
  ],
  rawImages: [
    { src: 'images/MyNewProject/graphic1.png', caption: 'Описание 1-го эскиза / макета' }
  ]
};

------------------------------------------------------------------------------
ШАГ 3. Подключите файл в js/projects/index.js
------------------------------------------------------------------------------
Откройте файл `js/projects/index.js` и добавьте ровно 2 строчки:

1) Вверху импорт файла:
   import { myproject } from './myproject.js';

2) Внутри PROJECTS_DATA добавьте имя переменной:
   export const PROJECTS_DATA = {
     curators,
     powerq,
     myproject   // <-- ваш новый проект
   };

------------------------------------------------------------------------------
ГОТОВО!
------------------------------------------------------------------------------
Сохраните файлы и обновите страницу в браузере. Новый проект автоматически
появится везде на вашем сайте!
==============================================================================
